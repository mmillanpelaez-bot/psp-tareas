# PSP · Tareas de clase


Módulo Programación de Servicios y Procesos · CFGS DAM 2 · Curso 2026-2027

## Estructura

```
psp-tareas/
├── UD1-procesos/       tarea01 ... tarea05
├── UD2-hilos/          tarea06 ... tarea22
└── UD3-comunicaciones/ tarea23 ... 
```

## Cómo compilar y ejecutar una tarea

```bash
cd UD2-hilos/tarea13
javac Tarea13.java
java Tarea13
```

> Las carpetas `tarea12` y `tarea13` tienen clases con el mismo nombre
> (`Contador`, `Hilo`). Como se compilan por separado, no pasa nada, pero **no las compiles juntas** en el mismo directorio.
